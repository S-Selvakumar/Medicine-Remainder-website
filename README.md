## 📌 About

MediRemind helps users manage their daily medicine schedules,
reminders and medicine stock.

</div>

---

<div>
  
### ✨ Features

- 💊 Add, edit and delete medicines
- 📅 Schedule medicine times
- 🔔 Reminder notifications
- 🗣️ Voice reminders
- 📦 Medicine stock tracking
- 📊 Dose tracking
- 🌙 Dark mode
- 💾 Local browser storage
- 📱 Responsive design
  
</div>
